# Разработка

Для запуска нужны Node.js 24, npm 11 и локальный PostgreSQL. Инструкция — в
[README](README.md), детали окружения и миграций — в [docs/development.md](docs/development.md).

Изменения держите в границах существующих модулей. Время и состояние встречи
читаются из `occupancies`; условия записи и последовательная история сохраняются
неизменяемыми. Бизнес-правила проверяются сервером. Публичные DTO не должны
включать внутренние данные или секреты организатора.

Перед pull request выполните:

```sh
npm run lint
npm run typecheck
npm test -- --maxWorkers=2
npm run test:integration -- --maxWorkers=1
npm run build
```

Проверки PostgreSQL создают и удаляют собственные базы `slotly_test_*`. Для них
нужен локальный пользователь с правом `CREATE DATABASE`; рабочая база не очищается.
Не подставляйте публичную или production-базу. CI выполняет проверки с отдельным
PostgreSQL-сервисом и автоматически созданными локальными секретами.

В PR опишите изменение поведения и результаты проверок. Новые зависимости
фиксируйте точной версией вместе с `package-lock.json`. Миграции SQL и Drizzle
метаданные сопровождаются вместе; предыдущие миграции после публикации не
переписываются. Личные данные и реальные письма не подходят для фикстур.

Для UI-изменений проверяйте мобильный экран, клавиатуру и reduced motion. Новые
русские тексты размещайте в `src/i18n/messages/ru`. Скриншоты для обсуждений должны
содержать вымышленные данные. Временно созданные артефакты храните в `.local`.
