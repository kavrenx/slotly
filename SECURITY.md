# Безопасность

Slotly пока предназначен для локальной разработки и проверки MVP. Публикация
исходников не означает готовность к обслуживанию публичных пользователей.
Текущее состояние подготовки пилота описано в [документации](docs/development.md).

При сообщении об ошибке удаляйте из примеров адреса участников, личные ссылки,
одноразовые коды, cookies, пароли и переменные окружения. Уязвимости, позволяющие
получить чужие записи или обойти авторизацию, сообщайте владельцу репозитория
конфиденциально. Если доступна функция GitHub «Report a vulnerability», используйте
её вместо публичного issue.

Проверки секретов и исключения Git уменьшают вероятность случайной публикации,
но не заменяют проверку изменений. Перед отправкой смотрите `git diff --cached`
и выполняйте `npm run repo:check`. Реальные `.env` и `.local` не входят в репозиторий.
