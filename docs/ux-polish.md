# UX/UI polish — последовательность работ

Палитра, маршруты, серверные правила записи, снимки условий, транзакции и защита
OTP сохраняются. Каждый пакет — отдельный проверяемый результат.

## Пакет 1 — публичная запись (готов)

- [x] Сетка слотов, ограниченная аккуратная прокрутка, состояния и обновление.
- [x] Компактный выбор с датой, временем, зоной и понятной кнопкой продолжения.
- [x] Единые компактные этапы «Время → Контакты → Подтверждение».
- [x] Контакты, ошибки, загрузка и возврат без потери исправимых данных.
- [x] Вставка шестизначного кода, таймер и повторная отправка по прежним лимитам.
- [x] Экран успеха с основной информацией и второстепенным номером записи.
- [x] Сквозная проверка записи, отмены, переноса и мобильных экранов.

Общие `BookingSteps` и `MeetingSummary` используются на всех этапах публичной
записи. Форматирование времени учитывает переход через полночь/год и разные
UTC-смещения начала и окончания встречи. `MeetingTime` в управлении записью
сохранён. Контакты хранятся только в памяти текущей страницы и очищаются после
успешного подтверждения; пароли, коды и ссылки не записываются в браузерное
хранилище. Поле кода принимает вставку шести цифр с пробелами без обрезания.
Клиентские блокировки Enter соответствуют состояниям кнопок; ограничения и
идемпотентность по-прежнему обеспечиваются сервером.

Проверено 1 ноября 2026: TypeScript, ESLint, 250 модульных и 196 интеграционных
тестов, production build, CSP/nonce и защитные заголовки пяти страниц. Модульные
тесты дополнены сценариями повторного часа DST, смены даты/года, дальней зоны
и вставки OTP. В Chromium проверены ширины 320/390/1280/1600, прокрутка 35 слотов,
пустой день, выбор/сброс/обновление, смена зоны, клавиатурный фокус и reduced motion.
На отдельной БД с отдельной локальной почтой пройдены контакты → неверный код →
вставка кода → подтверждение, повторная отправка и отклонение предыдущего кода,
перенос, отмена и история. Дополнительно проверены создание/публикация страницы,
кабинет и расписание. Реальные устройства Safari/Firefox отдельно не проверялись.
HTML-письма в этом пакете не изменялись; их визуальная проверка относится к пакету 2.

## Следующие отдельные пакеты

- [ ] Пакет 2: общий безопасный HTML-шаблон писем, оформление всех существующих
  событий, понятные даты, текстовая версия и проверка экранирования пользовательских данных.
- [ ] `.ics` без интеграций: название, описание, место, длительность и точные
  моменты времени, совместимость и отсутствие секретных ссылок в данных.
  Источник описания требует отдельного решения: текущий receipt его не содержит.
- [ ] Редактор страниц: популярные длительности, точные преобразования минут в
  часы/дни, сводка правил и публикации; существующая структура формы сохраняется.
- [ ] Список страниц: плотная адаптивная сетка, состояния, быстрые действия и архив.
- [ ] Расписание: компактность, обзор реальных рабочих интервалов и выходных,
  удобный список исключений; рабочие часы не выдаются за свободные слоты.

Для каждого пакета: типы, линтер, подходящие модульные/интеграционные тесты,
production build, браузер, мобильная ширина, клавиатура и reduced motion.
Незатронутые экраны и ограничения проверяются на регрессию. Публичный пилот и
подключение провайдеров остаются отдельной работой после дизайна.
